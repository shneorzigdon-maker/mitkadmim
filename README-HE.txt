מתקדמים v61.3 – ניהול חי והודעות אישיות

מה נוסף:
1. שליחת עדכון לכל המשתמשים.
2. הצגת משתמשים מחוברים עכשיו בזמן אמת (פעילות בשתי הדקות האחרונות).
3. הצגת המסך שבו המשתמש נמצא כרגע.
4. איתור אוטומטי של משתמשים שנתקעו בכושר או באנגלית.
5. שליחת הודעה אישית למשתמש.
6. הענקת נקודות.
7. איפוס כושר, אנגלית או כל ההתקדמות.

העלאה:
- העלו את כל תוכן התיקייה לשורש GitHub והחליפו קבצים קיימים.
- פרסמו מחדש את firestore.rules ב-Firebase > Firestore Database > Rules.
- בצעו Ctrl+Shift+R באתר ובחדר הבקרה.

הערה: מחיקת משתמש בחדר הבקרה מוחקת את מסמך Firestore בלבד, לא את חשבון Authentication.
