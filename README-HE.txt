מתקדמים v61.2 – עדכון חדר הבקרה

הקובץ מכיל רק את הקבצים שצריך להחליף או להוסיף במאגר הקיים.

העלאה ל-GitHub:
1. חלצו את קובץ ה-ZIP.
2. גררו את כל הקבצים והתיקיות לשורש המאגר mitkadmim ובחרו Replace לקבצים קיימים.
3. התיקייה control-room חייבת להישאר בשם זה.
4. ב-Firebase > Firestore Database > Rules החליפו את הכללים בתוכן firestore.rules ולחצו Publish.
5. בצעו Ctrl+Shift+R באתר.

כתובת חדר הבקרה:
https://shneorzigdon-maker.github.io/mitkadmim/control-room/

חשוב:
- מחיקת משתמש בחדר הבקרה מוחקת את מסמך הנתונים שלו מ-Firestore בלבד. היא אינה מוחקת את חשבון ההתחברות מ-Firebase Authentication, משום שמחיקה כזו דורשת שרת מאובטח / Cloud Function.
- "שליחת הודעה" יוצרת הודעה בתוך האפליקציה למשתמשים מחוברים. זו אינה הודעת Push לטלפון.
- מדדי "אימונים היום" ו"מילים היום" תלויים בכך שהאפליקציה שומרת תאריך לכל אימון/מילה. אם אין תאריכים בנתונים הישנים, המדד יציג רק נתונים שהאפליקציה כן מספקת.
