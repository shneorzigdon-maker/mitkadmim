# מתקדמים v65 – מספר פרופילים בחשבון

## מה חדש
- אפשר ליצור כמה פרופילים נפרדים תחת אותו חשבון Google או אימייל.
- לכל פרופיל נשמרים בנפרד: אנגלית, כושר, נקודות, הישגים ופרסים.
- מעבר בין פרופילים מתבצע דרך **הגדרות > חשבון ופרופילים**.
- כתובת המייל אינה מוצגת במסך הראשי. היא מופיעה רק בהגדרות.
- משתמשים קיימים עוברים אוטומטית למבנה החדש בלי למחוק את ההתקדמות הישנה.
- חדר הבקרה וכל הנתונים הקיימים נשמרו.
