# מתקדמים v67.1 – גרסה ישירה ויציבה

גרסה זו מתקנת את המסך הלבן על ידי ביטול מעטפת ה-iframe. האפליקציה הראשית נטענת ישירות מתוך index.html.

## העלאה
1. מחלצים את ה-ZIP.
2. מעלים את כל הקבצים ישירות לשורש מאגר GitHub.
3. מוודאים ש-index.html נמצא בשורש.
4. ממתינים לסימון ירוק ב-Actions.
5. פותחים את האתר עם ?v=671 או מבצעים Ctrl+Shift+R.

אין צורך לשנות Firebase או Firestore.
