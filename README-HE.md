# מתקדמים v66 – תיקוני שמירה, פרופילים וחדר בקרה

גרסה סטטית מוכנה להעלאה ל-GitHub Pages.

## תיקונים
- מסלול הכושר נשמר לצמיתות לכל פרופיל, מקומית וב-Firestore.
- מסך בניית המסלול אינו חוזר לאחר שכבר נשמר, אלא דרך כפתור ההגדרות בכושר.
- הוספת פרופילים תוקנה ונשמרת מיד בענן.
- מעבר ומחיקת פרופילים נשמרים באופן נפרד.
- חדר הבקרה נשמר, כולל הודעות כלליות ואישיות.
- אין הצגת מייל במסך הראשי.

יש להעלות את תוכן התיקייה לשורש המאגר. אין צורך לשנות Firebase.
