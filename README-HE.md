# מתקדמים v65.1 – גרסה מתוקנת

הגרסה אינה דורשת npm או Vite בזמן הפרסום ולכן עובדת גם כאשר GitHub Pages מוגדר ל-GitHub Actions וגם כאשר הקבצים נפתחים ישירות.

## העלאה
1. מחקו את קובצי הגרסה הקודמת במאגר (לא את המאגר עצמו).
2. העלו את כל התוכן שנמצא בתוך תיקייה זו לשורש המאגר.
3. ב-Settings > Pages בחרו GitHub Actions.
4. המתינו לסימון ירוק ב-Actions ורעננו עם Ctrl+F5.

Firebase, המשתמשים וחדר הבקרה נשמרים. כתובת המייל מוצגת רק בהגדרות. לכל חשבון ניתן ליצור כמה פרופילים.
