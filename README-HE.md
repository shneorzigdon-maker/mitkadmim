# מתקדמים v67.0 — גרסה מאוחדת ויציבה

- מסלול הכושר נשמר לצמיתות בנפרד לכל פרופיל, בענן ובמכשיר.
- לאחר בניית המסלול הוא לא מופיע שוב, אלא רק דרך שינוי בהגדרות הכושר.
- הוספת פרופיל, החלפה ומחיקה תוקנו.
- המייל מוצג רק בהגדרות.
- הודעות אישיות תוקנו ללא צורך באינדקס Firestore נוסף.
- חדר הבקרה כולל הודעות כלליות ואישיות, נקודות, איפוסים, נוכחות וייצוא.
- מטמון v67 מונע טעינת קוד ישן.

מעלים את כל הקבצים ישירות לשורש מאגר GitHub. לאחר הפרסום מבצעים Ctrl+Shift+R פעם אחת.
